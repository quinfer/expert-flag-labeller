# MSc-Themed-Research-Project

This repository contains experiments and tooling for NI flag classification, inspired by prompt-based CLIP variants and the methodology in Li et al. (2023).

## Structure
- `data/`: main experiments, datasets, training/evaluation scripts, and outputs
- `final_code/`: upstream baseline code aligned with the referenced paper
- `flag_classification_adaptation/`: exploratory adaptation work
- `docs/`: project documentation and progress notes
- `scripts/`: setup and utility scripts
- `archive/`: archived assets and large files

## Quick start
- See `docs/SETUP.md` for environment and data preparation
- See `docs/EXPERIMENTS.md` for how to run baselines and evaluations
- See `docs/PROGRESS.md` for status and next steps
